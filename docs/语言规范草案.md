# BlackLang 语言规范（草案 v0.1）

> 面向 AI 的编程语言。本文为 Phase 0 的概念级语法草案，后续以 AST 与实现为准。

## 0. 设计目标速览

- 主要作者为 **AI**（LLM / 智能体），人类只做审查。
- 性能目标：**介于 Python 与 C 之间**（AOT/JIT 编译）。
- **安全默认**：内存安全 + 权限作为语言特性。
- **互操作**：统一语法调用 Python / JS / TS / Go / Rust / C/C++ 及前后端框架。

## 1. Hello World

```black
run main:
    print("Hello, BlackLang!")
```

对标 C 的 `<stdio.h>`、Python 的 `if __name__ == "__main__"`——直接 `run main` 即程序入口，零样板。

## 2. 声明式默认

```black
// 一行起 HTTP 服务
http serve :8080 {
    "/"  => "BlackLang is running"
    "/api" => json {status: "ok"}
}

// 一行读文件
let data = read("config.json")    // 自动解析 JSON

// 一行并发
par for task in tasks: do(task)
```

## 3. 类型与所有权（安全支柱）

```black
// 所有权与借用，编译器校验，无 GC 停顿（可混合 GC 模式）
struct Account:
    owner: string
    balance: float

fn transfer(from: &Account, to: &Account, amount: float) -> bool:
    if from.balance < amount: return false
    from.balance -= amount
    to.balance += amount
    return true
```

## 4. 权限作为语言特性

```black
// 能力标注：此区块只读文件系统、无网络、无进程
sandbox readonly-fs:
    let v = read("input.txt")
    // ❌ 网络调用在此处编译不通过

// 网络可用才可声明
sandbox net:
    http post("https://api.example.com", payload)
```

能力标注随代码编译，CI 自动校验，AI 无法静默越权。

## 5. 互操作（Interop Bus）

```black
// 声明式绑定：调用外部语言/框架
use python: { numpy, pandas }
use node:   { express }
use go:     { net/http }
use c:      { libcurl }

// 统一调用界面
let arr = numpy.zeros([1000, 1000])     // 底层走 C
let resp = express.get("/users")         // 前端框架直调
```

## 5.5 自定义类型：`struct`

```
struct Point {
    x: int,
    y: int
}

// 方法：Type.method，self 自动绑定
fn Point.len2(self) {
    return self.x * self.x + self.y * self.y
}

run main: {
    let p = Point(3, 4)      // 位置构造：字段按声明顺序
    print(p.x)               // 字段访问（属性）
    print(p["y"])            // 字段访问（下标，便于与 JSON 互操作）
    print(p.len2())          // 方法调用
    p.x = 30                 // 字段赋值
    print(p)
}
```

- **位置构造**：`Point(3, 4)`——不引入新的字面量语法，避免与块 `{}` 产生歧义。
- **双访问**：`p.x` 与 `p["x"]` 等价；结构可与 JSON 直接互转。
- **方法**：`fn Type.method(self, ...)`，`p.method(...)` 自动补 `self`。
- **打印**：`print(p)` → `Point(x=30, y=4)`，便于 AI 读输出自纠。
- 构造参数个数在**编译期**校验（字段数不符即报错）。

## 5.6 执行后端（同一份源码，五条路径）

| 路径 | 命令 | 说明 |
|------|------|------|
| 解释(VM) | `blacklang f.bl` | 免编译、持久状态、互操作；~35–57x CPython |
| AOT→Python | `codegen.py` | 直译 Python；≈1.0x CPython；零工具链 |
| AOT→C | `blacklang --native f.bl` | 生成 C → clang；0.16–0.94x CPython |
| AOT→LLVM | `blacklang --llvm f.bl` | 生成 LLVM IR → clang；**0.15–0.52x CPython** |
| LLVM JIT | `blacklang --jit f.bl` | llvmlite MCJIT 进程内；同 LLVM 速度且**零构建** |

所有后端在支持子集内**输出逐字节一致**（由 `TestCrossPathConsistency` 保证）。
不支持的构造（互操作、字典、`struct`）会给出 `BL2001` 诊断并**自动回退**到 VM。

> `struct` 目前支持 VM / 树遍历 / AOT→Python；C 与 LLVM 后端暂不支持并回退
> （LLVM 侧的 struct 布局与字段 GEP 在路线图中）。

## 5.7 `let` 是声明，`x = v` 是赋值

- `let x = ...` 在**当前作用域声明**一个新变量；函数内即函数局部变量。
- `x = ...` 是**重新赋值**（更新已存在的绑定；顶层未声明时自动在全局建立）。
- 因此函数内局部变量是**可重入**的：递归调用不会互相覆盖。

## 6. 语法原则

1. **紧凑**：减少噪声 token，AI 在同一预算下产出更多逻辑。
2. **少魔法、多显式**：避免隐式转换，减少 AI 出错。
3. **局部可读**：人仍能审查——重点把「高风险」部分写得显眼。
4. **模块即单元**：一个文件就是一个可编译、可测试单元，便于回滚。

## 8. 文法初稿（EBNF 摘要，对应 MVP）

```ebnf
program      := stmt* ;
stmt         := let_stmt | assign_stmt | attr_assign | if_stmt | while_stmt
              | for_stmt | return_stmt | func_def | struct_def | sandbox_stmt
              | use_stmt | run_main | expr_stmt ;
let_stmt     := 'let' ID (':' type)? '=' expr ';'? ;
assign_stmt  := ID '=' expr ';'? ;
if_stmt      := 'if' expr ':'? block ('elif' expr ':'? block)* ('else' ':'? block)? ;
while_stmt   := 'while' expr ':'? block ;
for_stmt     := 'for' ID 'in' expr ':'? block ;
return_stmt  := 'return' expr? ';'? ;
func_def     := 'fn' (ID | ID '.' ID) '(' param (',' param)* ')' ('->' type)? ':'? block ;
struct_def   := 'struct' ID '{' (ID (':' type)? (',' | ';')?)* '}' ;
attr_assign  := ID '.' ID '=' expr ';'? ;
param        := ID (':' type)? ;
type         := 'int' | 'float' | 'string' | 'bool' | 'list' | ID ;
sandbox_stmt := 'sandbox' cap (cap)* ':' block ;
cap          := ID ('-' ID)* ;            (* 如 readonly-fs / write-fs / net *)
use_stmt     := 'use' ID ':' '{' ID (',' ID)* '}' ';'? ;
run_main     := 'run' 'main' ':' block ;
block        := '{' stmt* '}' ;
expr_stmt    := expr ';'? ;
expr         := or_expr ;
or_expr      := and_expr (('||'|'or') and_expr)* ;
and_expr     := equality (('&&'|'and') equality)* ;
equality     := comparison (('=='|'!=') comparison)* ;
comparison   := term (('<'|'>'|'<='|'>=') term)* ;
term         := factor (('+'|'-') factor)* ;
factor       := unary (('*'|'/'|'%') unary)* ;
unary        := ('-'|'!'|'not') unary | postfix ;
postfix      := primary (('(' args ')') | ('.' ID) | ('[' expr ']'))* ;
args         := expr (',' expr)* ;
primary      := NUMBER | STRING | 'true' | 'false' | ID
              | '(' expr ')' | '[' args ']' | '{' dict_pair (',' dict_pair)* '}' ;
dict_pair    := expr ':' expr ;
```

> 说明：分号可省略（遇 `}` 或块关键字即语句结束），以降低 AI 生成时的样板噪音。
>
> Phase 4 注：`use python: {mod}` / `use node: {mod}` 经 Interop Bus 真实调入宿主语言——
> Python 直接桥（属性/调用/下标全透传），Node 走 JSON-RPC 子进程并自适应 `node:` 前缀。
> 类型标注（`: int`、`-> int`）用于编译期类型检查（typechecker）。
